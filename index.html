FixLoop Studio — Master Feature Roadmap

Checklist of what’s built, what’s next, and what to add later (beginner → advanced friendly).

Current Features Already built

  • [✓] CLI runner
  • [✓] Iteration repair loop
  • [✓] Timeout control
  • [✓] Workdir targeting
  • [✓] File mode / Command mode
  • [✓] JSON report output
  • [✓] GUI: code editor panel + open/save
  • [✓] GUI: live output streaming + Stop button
  • [✓] GUI: error popups
  • [✓] GUI: dark/light theme toggle
  • [✓] AI + non‑AI repair are currently placeholders (stubs)

Phase 1 — Essential Build next

  • [ ] Safe patch system: snapshot + diff preview + approve/reject + rollback
  • [ ] Project mode: run a whole folder (entrypoints + pytest)
  • [ ] Multi‑file repair cycles
  • [ ] Smart fixers before AI: ruff, black, import fixes, mypy, syntax pass
  • [ ] Dependency detection (missing packages, pip checks)
Why this phase matters

This is the foundation that makes FixLoop safe + useful for real projects (and not scary to novices).

Phase 2 — Advanced Capabilities Power

  • [ ] Real AI repair engine (traceback → context → minimal patch → validate)
  • [ ] Plugin architecture (custom fixers, language modules, external tool injection)

Phase 3 — Professional Tooling Polish

  • [ ] Built‑in terminal panel
  • [ ] Project file explorer (tree + click to open)
  • [ ] Syntax highlighting (Python first)
  • [ ] Tabbed file editing
  • [ ] Embedded test runner

Phase 4 — Intelligence Layer Smart

  • [ ] Error intelligence panel (type, explanation, risk level, strategy)
  • [ ] Learning system (track frequent errors/fixes, adapt strategy)

Phase 5 — User Experience Tiers Beginner → Pro

  • [ ] Beginner mode: one‑click “Fix Project” + simple explanations
  • [ ] Intermediate: show iterations + diffs + rollback
  • [ ] Advanced: strategy selection + plugin manager + language switching
  • [ ] Theme presets per skill level (novice / builder / pro)

Integrations to Inject Tooling

  • [ ] Formatting: Black, Ruff, autopep8
  • [ ] Static analysis: mypy, pylint, bandit
  • [ ] Testing: pytest, coverage
  • [ ] Dependencies: pip check, pipdeptree, Poetry support
  • [ ] Future languages: Node (ESLint/Prettier), C++ (clang-tidy), Rust (cargo check), Java (Maven/Gradle)

Vision Options Pick a direction

  • [ ] A) AI Debug Assistant
  • [ ] B) Automated Stability Engine
  • [ ] C) AI IDE Replacement
  • [ ] D) Cross‑language Auto‑Repair Platform

Tip: If you want “super advanced” without being scary, build Phase 1 (safe patch + diffs + project mode) first.
